# This project

**This file is yours.** `scc` ships it as a stub, records that it did, and never
touches it again — an upgrade will leave whatever you write here alone. It is also
the reason `scc` needs no configuration file: the commands below are Markdown, which
the orchestrator already reads, and `scc` itself runs neither of them.

These are the commands `.github/workflows/ci.yml` runs, in the order it runs them. CI is
the authority; if the two ever disagree, the workflow is right and this file is stale.

## Commands

```bash
# Build — install the environment. There is no compile step; the wasm module is vendored.
uv sync --group dev

# Test — the whole suite
uv run pytest

# Test — one file or one test (used after every task; scope, not suite)
uv run pytest tests/cli/test_index.py
uv run pytest tests/cli/test_index.py -k anchor

# Lint — the best-practices layer that finds what tests do not
uv run ruff check .

# Types — strict over src/, and a gate in CI exactly like the lint
uv run mypy

# Format check / format
uv run ruff format --check .
uv run ruff format .

# Artifacts — the shape of specs, plans and docs. Exit 2 is a failure here, not a crash.
npx @protonspy/scc validate
```

## Conventions

- **Branch names:** `feat/<slug>`, `fix/<slug>`, `docs/<slug>`, `chore/<slug>`.
- **Commits:** Conventional Commits, scoped by the module the change lands in —
  `fix(cli/sweep,cli/gate): …`, `feat(cli/index,cli/formats): …`. The body says what
  changed and why, in full sentences; it is read months later by someone with no context.
- **Every task runs the lint and the types, not just the tests.** `mypy` is `strict` over
  `src/` and CI fails on it exactly as it fails on a red test.
- **What a new contributor gets wrong first:** writing to a path instead of through
  `ssc.cli.atomic`. `write_new` and `replace` are the only two ways a file is written, and
  inside a workspace they are reached through a `Directory` handle rather than a `Path` —
  see [[workspace-binding]] in the wiki for why, and `src/ssc/cli/atomic.py` for how.

## Boundaries

- **`vendor/pixel-snapper.wasm` and `vendor/LICENSE`** — a patched upstream build, force-
  included into the wheel. Not rebuilt here; see `adr:0002` and `adr:0003`.
- **`src/ssc/data/models.json`** — regenerated by `scripts/fetch_model_schemas.py` from the
  providers' published OpenAPI documents, never hand-edited.
- **A merged ADR under `docs/adr/`** — superseded with a new record, never rewritten.
- **A `schema` constant** — `dist/index.json`, `meta.json`, a job, a gate and a budget
  record each carry one. Changing a shape without incrementing it breaks a reader that is
  not in this repository; `adr:0010` is the rule for the index.
- **Platform-conditional code in `src/ssc/cli/atomic.py`** — a change there is unverified
  until it has run on the other platform. That is not a style preference; it is the defect
  described in [[workspace-binding]].
